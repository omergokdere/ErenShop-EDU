ErenShop API

Mini Sipariş ve Stok Yönetim Servisi — Eğitim Projesi

Python FastAPI + Microsoft SQL Server ile geliştirilmiş, eğitim amaçlı bir backend API projesidir.

Proje Amacı

Bu proje, başlangıç/orta seviye geliştiricilerin şunları öğrenmesi için hazırlanmıştır:

  • MSSQL'de veritabanı ve tablo oluşturma
  • Primary Key ve Foreign Key ilişkileri
  • SQL: SELECT, INSERT, UPDATE, DELETE, JOIN, GROUP BY
  • FastAPI ile REST API geliştirme
  • GET, POST, PUT, DELETE metodları
  • Postman ile API testi
  • Transaction mantığı
  • Hata yönetimi ve HTTP status kodları
  • Swagger arayüzü ile API inceleme

Teknolojiler

KatmanTeknoloji
BackendPython 3.10+ / FastAPI
VeritabanıMicrosoft SQL Server
DB Bağlantısıpyodbc
API TestiPostman
DokümantasyonSwagger (otomatik) + HTML

# 1. Sanal ortam oluştur

⚙️ Kurulum Kılavuzu

Windows ortamında, VSCode + MSSQL Server + Postman ile adım adım kurulum.

2. Python Kurulumu

  1. https://python.org adresinden Python 3.10+ indir
  2. Kurulum sırasında "Add Python to PATH" seçeneğini işaretle
  3. PowerShell'de test et:
python --version
pip --version

3. VSCode ile Projeyi Açma

  1. VSCode'u aç → File → Open Folder
  2. erenshop-api klasörünü seç
  3. Python extension kurulu değilse Extensions'dan Microsoft Python extension'ını kur

4. Sanal Ortam Oluşturma

VSCode'da terminal aç: Ctrl + ~

# Sanal ortam oluştur
python -m venv venv

# Aktif et (Windows)
venv\Scripts\activate

Terminal başında (venv) görünüyorsa aktif demektir.

Neden sanal ortam? Projeye özel kütüphaneleri izole eder, diğer projelerle çakışma olmaz.

5. Bağımlılıkları Yükleme

pip install -r requirements.txt

Yüklenen başlıca paketler:

  • fastapi — API framework
  • uvicorn — ASGI sunucu
  • pyodbc — MSSQL bağlantısı
  • python-dotenv — .env okuyucu
  • pydantic — veri doğrulama
  • python-docx — Word şablonu üretme/okuma (Eğitim Platformu için)
  • python-multipart — dosya yükleme (Eğitim Platformu için)
Önemli: Bağımlılıkları yükledikten sonra eğitim platformunun çalışması için python-docx ve python-multipart'ın kurulu olduğundan emin ol. Bunlar şablon Word dosyası üretmek ve Eren'in yüklediği dokümanı almak için gereklidir.

6. Veritabanı Oluşturma (SSMS)

  1. SSMS'i aç, sunucuya bağlan (genellikle localhost)
  2. New Query → sql/01_create_database.sql içeriğini yapıştır → F5
  3. "ErenShopDB başarıyla oluşturuldu." mesajını gör

Sık Karşılaşılan Hatalar

❌ pyodbc.InterfaceError: ('IM002', ...)

Sebep: ODBC Driver kurulu değil.
Çözüm: "ODBC Driver 17 for SQL Server" indir ve kur: https://aka.ms/downloadmsodbcsql

❌ Login failed for user

Sebep: Kullanıcı adı/şifre yanlış.
Çözüm: .env dosyasındaki DB_USER ve DB_PASSWORD değerlerini kontrol et.

❌ Cannot open database "ErenShopDB"

Sebep: Veritabanı oluşturulmamış.
Çözüm: SSMS'te 01_create_database.sql scriptini çalıştır.

❌ ModuleNotFoundError: No module named 'fastapi'

Sebep: Sanal ortam aktif değil veya paketler yüklenmemiş.

venv\Scripts\activate
pip install -r requirements.txt

❌ 422 Unprocessable Entity

Sebep: Request body formatı yanlış.
Çözüm: Postman'da Body → raw → JSON seç. Swagger'da örnek format var.

❌ Invalid object name 'TrainingUsers' (veya BusinessRequests, SqlQuestions)

Sebep: Eğitim platformu tabloları henüz oluşturulmamış.
Çözüm: SSMS'te sırayla şu 3 dosyayı çalıştır:

  1. sql/08_training_tables.sql
  2. sql/09_seed_business_requests.sql
  3. sql/10_seed_sql_questions.sql

❌ ModuleNotFoundError: No module named 'docx'

Sebep: Eğitim platformu için gereken python-docx kütüphanesi yüklü değil.
Çözüm:

venv\Scripts\activate
pip install python-docx python-multipart

Veya tüm bağımlılıkları yeniden yükle: pip install -r requirements.txt

❌ Word şablonu indirilemiyor / "Sadece .docx dosyalari kabul edilir"

Sebep: Yüklediğin dosya .docx değil (.doc, .docm, .pdf vb.).
Çözüm: Word'de "Farklı Kaydet" → Word Belgesi (*.docx) formatını seç.

🔌 API Dokümanı

Tüm endpoint'lerin açıklaması, parametreleri ve örnek cevapları.

Standart Response Formatı

// Başarılı:
{ "success": true,  "message": "İşlem başarılı.", "data": {} }

// Hatalı:
{ "success": false, "message": "Hata açıklaması.", "data": null }

HTTP Status Kodları

KodAnlamNe zaman?
200OKBaşarılı GET, PUT, DELETE
201CreatedBaşarılı POST (yeni kayıt)
400Bad RequestGeçersiz istek, iş kuralı hatası
404Not FoundKayıt bulunamadı
422Unprocessable EntityBody format hatası
500Internal Server ErrorBeklenmedik sunucu hatası

1. Health Check

GET /api/health

API ve veritabanı durumunu kontrol eder.

{ "success": true, "message": "API ve veritabanı bağlantısı sağlıklı.",
  "data": { "api": "ok", "database": "ok" } }

2. Categories

GET /api/categories — Tüm aktif kategorileri listeler.
GET /api/categories/{category_id} — Tek kategori getirir.
POST /api/categories 
{ "name": "Elektronik", "description": "Elektronik ürünler" }
PUT /api/categories/{category_id} — Tüm alanlar opsiyonel. 
{ "name": "Yeni Ad", "description": "Yeni açıklama", "is_active": true }
DELETE /api/categories/{category_id} — Soft delete (IsActive=0).

3. Products

GET /api/products — Tüm aktif ürünleri listeler.
GET /api/products/search?keyword=mouse — Ürün adı/açıklamasında arama.
GET /api/products/category/{category_id} — Kategoriye göre listeler.
GET /api/products/{product_id} — Tek ürün getirir.
POST /api/products 
{ "categoryId": 1, "name": "Kablosuz Mouse",
  "description": "Bluetooth destekli", "price": 450.00, "stock": 25 }
PUT /api/products/{product_id} — Günceller. Tüm alanlar opsiyonel.
DELETE /api/products/{product_id} — Soft delete.

4. Customers

GET /api/customers — Tüm aktif müşterileri listeler.
GET /api/customers/{customer_id} — Tek müşteri.
POST /api/customers — Email benzersiz olmalı. 
{ "first_name": "Eren", "last_name": "Gokdere",
  "email": "eren@example.com", "phone": "05550000000", "address": "İstanbul" }
PUT /api/customers/{customer_id}
DELETE /api/customers/{customer_id}
GET /api/customers/{customer_id}/orders — Müşterinin siparişleri.

5. Cart (Sepet)

POST /api/cart/add — Sepete ürün ekler. Sepet yoksa otomatik oluşturur. 
{ "customerId": 1, "productId": 1, "quantity": 2 }

İş kuralları: müşteri aktif, ürün aktif, stok yeterli olmalı. Ürün zaten varsa miktar güncellenir.

GET /api/cart/{customer_id} — Sepeti ve toplam tutarı getirir. 
{ "data": { "cart_id": 1, "items": [
    { "CartItemId": 1, "ProductName": "Kablosuz Mouse",
      "Quantity": 2, "UnitPrice": 450.00, "LineTotal": 900.00 }
  ], "total": 900.00 } }
DELETE /api/cart/items/{cart_item_id} — Sepetten tek ürün sil.
DELETE /api/cart/clear/{customer_id} — Sepeti tamamen temizle.

6. Orders (Siparişler)

POST /api/orders/create-from-cart — Sepeti siparişe dönüştürür. 
{ "customerId": 1 }

Transaction: stok düşer, sepet temizlenir, sipariş "Pending" olur. Herhangi bir hata → tüm işlem geri alınır.

GET /api/orders — Tüm siparişler.
GET /api/orders/{order_id} — Sipariş detayı + ürün listesi.
GET /api/orders/customer/{customer_id} — Müşterinin siparişleri.
PUT /api/orders/{order_id}/status 
{ "status": "Processing" }

Geçerli durumlar: Pending → Processing → Shipped → Delivered | Paid | PaymentFailed | Cancelled

7. Payments (Ödeme)

POST /api/payments/mock-pay — Mock ödeme simülasyonu. 
{ "orderId": 1, "paymentType": "CreditCard",
  "amount": 900.00, "forceFail": false }

forceFail: false → başarılı (Paid) | forceFail: true → başarısız (PaymentFailed)

8. Reports (Raporlar)

GET /api/reports/daily-sales?date=2026-04-28 — Günlük satış raporu. date opsiyonel (varsayılan: bugün).
GET /api/reports/top-products?limit=10 — En çok satılan ürünler.
GET /api/reports/customer-summary/{customer_id} — Müşteri sipariş/harcama özeti.
GET /api/reports/category-sales — Kategori bazında satış özeti.
GET /api/reports/low-stock-products?threshold=10 — Stoğu azalan ürünler.

🗄️ SQL Eğitim Notları

1. Veritabanı ve Tablo Nedir?

Veritabanı (Database): Tabloları içeren konteyner. Bizim veritabanımız: ErenShopDB

Tablo (Table): Excel tablosu gibi düşün. Sütunlar ve satırlar vardır.

Categories Tablosu:
+----+------------+---------------------+----------+
| Id | Name       | Description         | IsActive |
+----+------------+---------------------+----------+
|  1 | Elektronik | Elektronik ürünler  |    1     |
|  2 | Ofis       | Ofis malzemeleri    |    1     |
+----+------------+---------------------+----------+

2. Primary Key (Birincil Anahtar)

Her tablodaki her satırı benzersiz şekilde tanımlar.

CREATE TABLE Categories (
    Id INT IDENTITY(1,1) PRIMARY KEY,  -- Otomatik 1'den artar
    Name NVARCHAR(100) NOT NULL,
    ...
);

Kural: İki satır aynı Id'ye sahip olamaz.

3. Foreign Key (Yabancı Anahtar)

Bir tablodaki sütunun başka bir tabloya referans vermesidir.

-- Products.CategoryId → Categories.Id'yi referans alır
CONSTRAINT FK_Products_Categories FOREIGN KEY (CategoryId)
    REFERENCES Categories(Id)
Categories (Id=1, Name="Elektronik")
       ↑
Products (CategoryId=1, Name="Mouse")

4. Temel SQL Komutları

SELECT — Veri Okuma

SELECT * FROM Products;
SELECT Name, Price FROM Products;
SELECT * FROM Products WHERE IsActive = 1;
SELECT * FROM Products ORDER BY Price DESC;

INSERT — Veri Ekleme

INSERT INTO Categories (Name, Description, IsActive, CreatedAt, UpdatedAt)
VALUES (N'Elektronik', N'Elektronik ürünler', 1, GETDATE(), GETDATE());
⚠️ NVARCHAR sütunlara Türkçe karakter eklerken N'...' prefix'ini kullan!

UPDATE — Veri Güncelleme

-- DİKKAT: WHERE yazmayı unutma! Yoksa tüm satırlar güncellenir!
UPDATE Products
SET Stock = 20, UpdatedAt = GETDATE()
WHERE Id = 1;

DELETE — Veri Silme

-- DİKKAT: WHERE yazmayı unutma!
DELETE FROM CartItems WHERE CartId = 1;

5. JOIN Kavramı

İki tabloyu birleştirerek sorgulama. Ürün tablosunda sadece CategoryId var, kategori adını almak için JOIN kullanırız.

-- Ürünleri kategori adıyla getir
SELECT p.Name, p.Price, c.Name AS CategoryName
FROM Products p
INNER JOIN Categories c ON p.CategoryId = c.Id;
JOIN TipiAçıklama
INNER JOINHer iki tabloda da eşleşen kayıtları getirir
LEFT JOINSol tablonun tüm kayıtları + sağ tabloda eşleşenler

6. Aggregate Fonksiyonlar

COUNT(*)       -- Kaç satır var?
SUM(Price)     -- Toplamı hesapla
AVG(Price)     -- Ortalamayı hesapla
MIN(Price)     -- En küçük değer
MAX(Price)     -- En büyük değer

7. GROUP BY

Verileri gruplandırarak özet bilgi almak için.

-- Kategorilere göre ürün sayısı
SELECT CategoryId, COUNT(*) AS ProductCount
FROM Products
GROUP BY CategoryId;

-- Sipariş durumuna göre toplam tutar
SELECT Status, SUM(TotalAmount) AS Total
FROM Orders
GROUP BY Status;
Kural: SELECT'teki her sütun ya GROUP BY'da olmalı ya da aggregate fonksiyon içinde olmalı.

8. HAVING

GROUP BY sonrasında filtre. WHERE gruplama öncesi, HAVING gruplama sonrası çalışır.

-- En az 3 ürünü olan kategoriler
SELECT CategoryId, COUNT(*) AS ProductCount
FROM Products
GROUP BY CategoryId
HAVING COUNT(*) >= 3;

9. Transaction Kavramı

Transaction: Birden fazla SQL işleminin "ya hep ya hiç" prensibiyle çalışması.

Örnek — Sipariş oluşturma:

  1. Orders tablosuna kayıt ekle
  2. OrderItems tablosuna satırlar ekle
  3. Products tablosundan stok düş
  4. CartItems tablosunu temizle

3. adımda hata olursa 1. ve 2. adımlar da geri alınmalı. Yarım kalan sipariş olmaz!

BEGIN TRANSACTION;
BEGIN TRY
    INSERT INTO Orders (...) VALUES (...);
    INSERT INTO OrderItems (...) VALUES (...);
    UPDATE Products SET Stock = Stock - 1 WHERE Id = 1;
    COMMIT TRANSACTION;
END TRY
BEGIN CATCH
    ROLLBACK TRANSACTION;
    PRINT 'Hata: ' + ERROR_MESSAGE();
END CATCH;

Python/pyodbc'de Transaction:

try:
    cursor.execute("INSERT ...")
    cursor.execute("UPDATE ...")
    conn.commit()   # Başarılı → kaydet
except:
    conn.rollback() # Hata → geri al

10. Soft Delete (Mantıksal Silme)

Veritabanından fiziksel olarak silmek yerine IsActive = 0 yapmak.

-- Fiziksel silme (geri dönüşü yok!)
DELETE FROM Products WHERE Id = 1;

-- Soft delete (geri getirilebilir)
UPDATE Products SET IsActive = 0 WHERE Id = 1;

Neden tercih ederiz? Veri kaybı olmaz, geçmişi izleyebiliriz, siparişlerde bağlantılı ürün hâlâ görünür.

11. Faydalı MSSQL Fonksiyonları

GETDATE()           -- Şu anki tarih ve saat
CAST(x AS DATE)     -- Tarih-saati sadece tarihe çevir
ISNULL(x, 0)        -- NULL ise 0 kullan
LEN('metin')        -- Metin uzunluğu
UPPER('metin')      -- Büyük harf
LOWER('Metin')      -- Küçük harf
CONCAT(a, ' ', b)   -- Metinleri birleştir
